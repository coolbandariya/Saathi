# Saathi Test Matrix

| Area | Minimum gate |
|---|---|
| API | health, validation, deterministic routing |
| Database | migration success, RLS isolation, consent enforcement |
| Agent | structured outputs, tool-only factual answers, fallback behavior |
| Voice | STT/TTS adapter errors, language selection, interruption handling |
| Telephony | webhook signature, idempotency, call state, consent, quiet hours |
| Tasks | create, resume, complete, cancel, callback scheduling |
| Documents | upload validation, OCR extraction, unsafe/unsupported file handling |
| Volunteer | escalation, assignment, resolution, audit trail |
| Frontend | production build, responsive layout, accessibility basics |
| E2E | complete demo from voice request to task/resume/escalation |
